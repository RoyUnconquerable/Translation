# Reference Talents and Hundred Lives

Updated 16 September 2026. The final Word manuscript and the owner's choices are
approved. Earlier Pass 5 to 8 pending labels no longer govern their approval status.

These templates govern recurring text for the SAME Talent, tier, mechanic and life
stage. The first approved description is canonical when the description repeats
unchanged in meaning. Do not erase an upgrade, new limitation, variable value or
source-supported change to force a template. Raise a real new conflict in the term batch.
Keep approved descriptive wording even when a broader prose preference differs.

Examples below show text inside brackets; every rendered panel is bold, including
its brackets. Remove only a terminal period or exclamation mark immediately before
the closing bracket. Keep internal punctuation, question marks and three-dot ellipses.
The description table records sentence content with normal sentence punctuation;
that punctuation is not an exception to the closing-bracket rule. Talent names stay
roman, and bold panels never take italics. Do not add unprovided fields, choices,
counts or tiers. Preserve source information and order, using the approved display-only
paragraph exception in `Reference_Formatting_Rules.md` when needed.

## Talent panels

- Reveal line: 【You have obtained the <Tier> Talent: <Name>】 (Golden and Prismatic). The two early reveals keep "awakened": 【You have awakened the White Talent: Dual Cultivation Prodigy】, 【You have awakened the Purple Talent: Got Some Skills】. No terminal period or exclamation mark before the closing bracket.
- Description panel: 【<Name>: <description>】. The first approved appearance is canonical for an unchanged description; later repeats match its wording subject to the display punctuation rule above.
- Tier words: White, Purple, Golden, Prismatic. Talent names are roman (never italic).

## Status panel

Use these labels for the corresponding fields actually present. Preserve source field order and values; do not insert missing fields. The reference order is: 【Name: 】, 【Age: 】, 【Cultivation: 】, 【Talents: 】, 【Cultivation Technique: 】, 【Divine Abilities: 】, 【Treasures: 】, 【Book of a Hundred Lives Pages: N】, 【Anchor Points: N】. Later panels add 【Dao Foundation: 】, 【Blessed Lands: 】, 【Fruition Attainments: 】. The plural labels are used regardless of how many items follow. Single-ability panels outside a status panel (Ch.1090 【Divine Ability: Drop of Heaven's Essence】) keep the singular.
